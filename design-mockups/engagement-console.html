Significance and relevant assertions

ISA 315 (Revised 2019) ¶29

An account is significant where it has one or more relevant assertion. The quantitative test runs against performance materiality automatically. The qualitative test is yours: tick an account whose size does not make it significant but whose nature does.

What can go wrong, and the controls that address it

ISA 315 ¶25–26

For each significant account, record what can go wrong against the assertion it would affect. Name the control that addresses it, or leave it to be answered substantively in the next step. A row with neither answer blocks gate G2.

Audit strategy per assertion

ISA 330 ¶6–8

Choose the strategy for each row. Controls reliance requires a named control and commits you to testing its operating effectiveness. Fully substantive holds control risk at maximum, and the sample size computed downstream rises with it.
