The spine: five levels deep

left to right, each column is one click

Entry

Sign in/loginEmail and password. On success you land on your most recent engagement; if you have none, on the firm dashboard.
Firm dashboard/dashboardPortfolio across all engagements: counts, priority queue, deadlines.
Engagements/engagementsThe register. Filter by year, partner, mine. Click a row to open it.
Entities/clientsClient master records. Reached from Settings and from “About {entity}”.

Click by click

from the hub outward
Where you clickTakes you toWhat it reveals
Phase ring on the hubstays on hubSwaps the Task status panel to that phase’s groups with their completion bars.
Group row in Task status/groups/:groupThe group’s detail tasks, each with status, assignee and due date.
Phase in the phase bar/phase/:sectionThe phase page: gate, completion, the phases that feed it and that it feeds, then every task numbered in the order performed, then the groups.
Task row on a phase page/sections/:itemIdThe task on its own page — see section 04.
Attention item on the hubthe owning pageJumps to whatever needs action: an unsigned paper, an open risk, a gate blocker.
Reference rail chiptools · tasks · cra · data · pbc · legal · teamDirect shortcut, plus Export file index as .xlsx.
Tools in the phase bar/toolsEight tools, each with the phase it belongs to and the working papers it feeds. Independence inquiry panel below.

About {entity} →/clients/:idThe entity master record and its engagement history.

PanelWhat it holdsSource

Where the site does not match the proposal

stated plainly
ItemProposalLive site

Task inventory36 named papers, ACC-1 to CON-1359 tasks on a full engagement, using the platform’s own codesnot reconciled
Paper contentProcedures with expected sources, Yes/No factor checklists, standards narrative, definitionsFields generated from the task’s group — the 43,000 words are not portedgap
.docx templatesOne per taskThree real ones (D3.1, E500, E510); every other task renders a four-line generic stubthin
Template systemsOneTwo, unaware of each other: lib/templates.ts renders .docx, lib/working-papers.ts saves to form_responseto merge
Tools in the taskTool output shown inline in the paper it feedsBlue fields render their source hint; live values not wired yetpartial
What is genuinely in place: the four phases and their gates, the phase bar replacing the eleven-tab cluster, phase pages listing tasks in sequence with their linkages, standalone task pages each carrying a working paper that saves, all eight tools grouped in one place with the independence inquiry, the six-grade team ladder with direct task assignment, and one page shell across all 40 routes so nothing shifts as you navigate.
