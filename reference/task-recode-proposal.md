## What the migration touches

- `file_item.code` per engagement (mapping UPDATE, dev + prod)
- Stored answers: `form_response` codes `wp:<old>` → `wp:<new>`
- Code literals: papers maps, task-groups members, file-index, cross-links, RAS dependency codes, lead-schedule INDEX_SECTION, seeded risk sections (E100/E350), E2E specs
- Lead-schedule indexes (A, C, E, K, T…) are untouched — they are account indexes, not task codes
